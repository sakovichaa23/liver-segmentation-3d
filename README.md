## О проекте
Специализированная медицинская система для автоматической 3D-сегментации печени и оценки её объёма по данным компьютерной томографии. Система выполнена в виде десктопного приложения с графическим интерфейсом и ориентирована на врачей-рентгенологов и хирургов для предоперационного планирования и волюметрии.

Система обрабатывает полный 3D-объем КТ с использованием глубокой сверточной нейронной сети 3D U-Net с остаточными (residual) связями, выполняет постобработку и восстанавливает маску в исходную анатомическую систему координат.

## Ключевые возможности
| Функция | Описание |
|---|---|
| Клинический режим | Синхронный просмотр КТ в трех ортогональных проекциях (аксиальная, корональная, сагиттальная) с перекрестной навигацией |
| 3D-сегментация | Автоматическое выделение паренхимы печени нейросетью 3D U-Net и постобработка (удаление шумов, заполнение полостей) |
| 3D-визуализация | Интерактивное построение трехмерной полигональной модели печени (вращение, масштабирование, ракурс) |
| Волюметрия | Автоматический расчет физического объема печени в миллилитрах (мл) на основе шага вокселей |
| Отчеты | Генерация формализованных PDF-протоколов с проекциями срезов, 3D-моделью, объемом и метаданными |
| История исследований | Сохранение и быстрый поиск пациентов, параметров сканирования и результатов сегментации в SQLite |
| Поддержка форматов | Загрузка NIfTI (.nii, .nii.gz), серий DICOM из папок и ZIP-архивов с сохранением нативной геометрии |

## Результаты диагностики
Система определяет:
- **Маска органа:** точная трехмерная бинарная маска паренхимы печени
- **Объем печени:** физический объем органа в миллилитрах (мл / см³)
- **Количество вокселей:** число положительных вокселей маски в нативном разрешении
- **Параметры геометрии:** размерность КТ-матрицы и шаг сканирования (spacing dx, dy, dz)
- **Время обработки:** длительность инференса нейросети и постобработки

## Технологический стек
| Компонент | Технология |
|---|---|
| Фреймворк ИИ | PyTorch (CUDA / CPU), AMP |
| Архитектура | Residual 3D U-Net (1.42 млн параметров) |
| Медицинские данные | pydicom, nibabel, SciPy, SimpleITK |
| Интерфейс | PyQt5 (десктопное приложение) |
| 3D-визуализация | Vedo, VTK, Scikit-Image (Marching Cubes) |
| База данных | SQLite (хранение пациентов и истории анализов) |
| Отчеты | ReportLab, Matplotlib (генерация PDF) |

## Как запустить

Локально:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/sakovichaa23/liver-segmentation-3d.git
cd liver-segmentation-3d
```

2. Создайте и активируйте виртуальное окружение:
```bash
# Для Windows:
python -m venv venv
venv\Scripts\activate

# Для Mac/Linux:
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Запустите программу:
```bash
python main.py
```

(Для пользователей Windows также доступен быстрый запуск через файл `start.bat`)
