# Сегментация печени по КТ (3D U-Net)

**Тема:** Разработка и исследование трёхмерной нейросетевой архитектуры для
автоматической сегментации и оценки объёма печени пациента по данным
компьютерной томографии.

## О проекте

Нейросетевая система автоматической сегментации печени на КТ и оценки её объёма.
Десктопное приложение с графическим интерфейсом для врачей-рентгенологов.

Система решает задачу **3D-сегментации** печени на КТ-томограммах с помощью
трёхмерной свёрточной сети (3D U-Net с остаточными блоками).

### Как это работает

```
1. Загрузка исследования        NIfTI (.nii/.nii.gz) или DICOM (папка / ZIP)
2. Предобработка               нормализация HU, обработка пропусков, resize 128³
3. Нейросетевая сегментация    обученная 3D U-Net → маска печени
4. Восстановление геометрии     маска возвращается к сетке исходной КТ
5. Постобработка               крупнейший объект, дыры, морфология
6. Результат                    три плоскости, 3D-модель, объём в мл
```

## Обучение модели

Ноутбук `notebook/3d.ipynb` содержит полный цикл:

1. загрузка данных LiTS (131 пара КТ + маски) и внешнего набора MSD;
2. препроцессинг: resize 128³, клип [-100, 200] HU, кэширование в `.npy`;
3. архитектура **3D U-Net** с остаточными блоками (1.42 млн параметров);
4. потери `DiceCELoss`, оптимизатор AdamW, `ReduceLROnPlateau`, AMP;
5. цикл обучения с early stopping;
6. метрики: Dice, IoU, Precision, Recall, confusion matrix, ROC-AUC;
7. визуализация и 3D-рендер.

Запуск: `jupyter notebook`, открыть `notebook/3d.ipynb`. В Colab — выбрать GPU (T4).

Результат — `model/best_3d_unet.pth`.

## Архитектура модели

```
Вход: (1, 1, 128, 128, 128)

enc1: ResidualBlock3D(1 → 16)     ─────────────┐
enc2: ResidualBlock3D(16 → 32)    ────────┐    │ skip
enc3: ResidualBlock3D(32 → 64)    ────┐   │    │
bottleneck: ResidualBlock3D(64 → 128)  │   │    │
dec3: up(128→64) + concat + Residual(128→64)  │   │
dec2: up(64→32)  + concat + Residual(64→32)   │
dec1: up(32→16)  + concat + Residual(32→16)  │
out: Conv3d(16 → 1)

Параметров: 1 422 785
```

Каждый `ResidualBlock3D`: `Conv3d → InstanceNorm3d → LeakyReLU → Dropout3d →
Conv3d → InstanceNorm3d → + skip → LeakyReLU`.

## Функциональность

### Основные функции

| Модуль | Что реализовано |
|---|---|
| Загрузка КТ | открыть `.nii`/`.nii.gz` или DICOM-папку/ZIP, отображение размеров и параметров вокселя |
| Предобработка | нормализация HU, обработка пропусков, подготовка 3D-массива |
| Нейросетевая сегментация | загрузка `best_3d_unet.pth`, предсказание маски, отображение хода обработки |
| Просмотр КТ | три ортогональные плоскости (аксиальная, корональная, сагиттальная) с перекрёстной навигацией |
| Наложение маски | полупрозрачная цветная маска + контур на КТ |
| Трёхмерная визуализация | поверхность печени, вращение, масштабирование, изменение ракурса |
| Расчёт объёма | подсчёт вокселей и вычисление объёма в мл |
| История исследований | сохранение пациента, даты, параметров и результатов в SQLite |
| Экспорт | маска в NIfTI, маска в DICOM, PDF-отчёт |

### Дополнительные функции

- Повторное открытие ранее обработанного исследования без повторного запуска нейросети.
- Удаление записи об исследовании из истории.
- Поиск по коду пациента и сортировка по дате.
- Просмотр информации о модели и её версии.
- Обработка ошибок: повреждённый файл, пустая маска, неподдерживаемые данные, отсутствующие веса.
- Кнопка сброса текущего просмотра.
- Сохранение исходной геометрии при экспорте маски.

## База данных SQLite

SQLite — хороший вариант для локального приложения: отдельный сервер не нужен,
база хранится в одном файле `data/liver.db`.

Три таблицы:

```
patients (patient_id, patient_code, created_at, notes)
    ↓
studies (study_id, patient_id, study_date, source_file, dimensions, spacing)
    ↓
segmentation_results (result_id, study_id, model_version, volume_ml,
                      voxel_count, processing_time, mask_path, created_at)
```

Связи позволяют хранить несколько исследований одного пациента и несколько
результатов обработки одного исследования.

В базе хранятся метаданные и результаты, а не сами массивы КТ. Исходные
исследования, маски и PDF сохраняются в отдельных папках приложения.

## PDF-отчёт

Одностраничный отчёт (A4), который содержит:

- код пациента и дату обработки;
- размеры исходного КТ-объёма и параметры вокселя;
- изображение: три плоскости с наложенной маской + 3D-модель печени;
- рассчитанный объём печени в мл;
- число вокселей маски;
- версию модели и время обработки.

Отчёт обозначается как результат работы исследовательского программного
инструмента, а не как самостоятельное медицинское заключение.
